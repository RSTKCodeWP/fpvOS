# RSTK product layer

**fpvOS** (this repository root) is the open Ascent firmware project.  
**RSTK** ([`rstk/`](rstk/)) is RSTKCodeWP’s product engineering: reverse kits, GT Pro bring-up, and tools.

| You want… | Go to… |
|-----------|--------|
| Build fpvOS as upstream documents | Root [`README.md`](README.md), branch **`main`** |
| GT Pro reverse kit + PS5280 driver | [`rstk/modules/gt-pro/`](rstk/modules/gt-pro/), branch **`GT-Rev`** |
| How this fork is organized | [`rstk/README.md`](rstk/README.md) |

Default GitHub branch for product artifacts: **`GT-Rev`** (tag **`GT-Rev`**).
